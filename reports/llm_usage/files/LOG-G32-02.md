```text
### Read first line, then continue iterating the same file

**Short answer (recommended):**

with open("file_in", "r") as f:
    first = f.readline()
    for line in f:
        # process remaining lines
        print(line, end="")


**Why this works**
- `f.readline()` reads the first line and advances the file pointer to the start of the second line.
- The `for line in f:` loop resumes from that current file position and yields the remaining lines without re-reading the first one. 

**Alternatives**
- Use `next(f)` instead of `f.readline()`:

with open("file_in") as f:
    first = next(f)
    for line in f:
        ...

- If you need the first line but also want to include it in the loop, you can `chain` it back:

from itertools import chain

with open("file_in") as f:
    first = f.readline()
    for line in chain([first], f):
        ...


Use the first pattern for the common case where you want to handle the first line separately and then process the rest.
```

```text
### Reassigning a global variable inside a function

Use the **`global`** statement inside the function to tell Python you mean the module‑level variable, then assign to it.


x = 10

def set_x_to_20():
    global x
    x = 20

print(x)   # 10
set_x_to_20()
print(x)   # 20


#### Notes
- **`global name`** must appear before you assign to `name` in that function.
- Without `global`, assigning to `name` creates a new local variable and does **not** change the module‑level variable.
- For mutable globals (lists, dicts), you can modify in place without `global` (e.g., `my_list.append(1)`), but to rebind the name to a new object you still need `global`.
```

```text
### Incrementing an object attribute in Python

You can increment an attribute on an object the same way you increment a variable: read it, add to it, and assign it back. The most common patterns:

#### 1. Simple increment

class Counter:
    def __init__(self):
        self.value = 0

c = Counter()
c.value += 1


#### 2. Ensure attribute exists (safe increment)

class Counter:
    pass

c = Counter()
if not hasattr(c, 'value'):
    c.value = 0
c.value += 1


#### 3. Use `getattr` with a default

class Counter:
    pass

c = Counter()
c.value = getattr(c, 'value', 0) + 1


#### 4. Encapsulate increment in a method (recommended for clarity)

class Counter:
    def __init__(self, start=0):
        self.value = start

    def increment(self, amount=1):
        self.value += amount

c = Counter()
c.increment()        # increments by 1
c.increment(5)       # increments by 5


#### 5. Thread-safe increment (when multiple threads modify the attribute)

import threading

class Counter:
    def __init__(self):
        self.value = 0
        self._lock = threading.Lock()

    def increment(self, amount=1):
        with self._lock:
            self.value += amount


---

**Quick note:** `+=` calls the attribute’s in-place add if available (e.g., lists), otherwise it falls back to normal addition and assignment. For numeric attributes `self.attr += 1` is the idiomatic and concise approach.
```

```text
### Set all array values to zero in Python 3

| **Method** | **When to use** | **Speed / notes** |
|---|---:|---|
| **`numpy.zeros_like(arr)` / `arr.fill(0)`** | Numeric arrays (NumPy) | **Fastest** for large numeric arrays; uses contiguous memory and C loops |
| **`arr[:] = 0`** | Python `list` or NumPy array | Fast and idiomatic; for lists it assigns the same integer value to each slot |
| **`[0] * n`** | Create a new list of zeros | Very fast for creating a new list; avoid for lists of mutable objects |
| **`array.array('i', [0])*n`** | Memory-efficient numeric arrays (built-in `array`) | Compact storage; faster than lists for numeric data |
| **`itertools.repeat(0, n)`** | Lazy zero sequence | Use when you need an iterator, not a concrete list |

---

#### Examples

##### NumPy (recommended for numeric work)

import numpy as np

# create an array
a = np.arange(10)

# set all values to zero in-place
a.fill(0)

# or create a new zero array with same shape/dtype
b = np.zeros_like(a)


**Why:** NumPy operations run in C and are vectorized, so `fill(0)` or `zeros_like` are much faster than Python-level loops for large arrays.

##### Python list (in-place)

lst = [1, 2, 3, 4, 5]
lst[:] = [0] * len(lst)   # replaces contents with zeros
# or
lst[:] = [0 for _ in lst] # equivalent, slightly slower


**Note:** `lst[:] = [0] * len(lst)` modifies the list in-place (keeps same object identity).

##### Create a new list of zeros

n = 1000000
zeros = [0] * n

**Note:** Very fast for creation; if you need to reuse an existing list object, assign into slice as above.

##### `array` module for compact numeric arrays

from array import array
a = array('i', range(10))
a = array('i', [0]) * len(a)   # creates new array of zeros
# or fill in-place
for i in range(len(a)):
    a[i] = 0

**Note:** `array` stores C-style numeric types and uses less memory than lists.

##### Lazy iterator

import itertools
zeros_iter = itertools.repeat(0, n)

**Note:** Produces values on demand; doesn't allocate memory for all zeros.

---

### Quick recommendation
- **If you work with numeric data:** use **NumPy** and `arr.fill(0)` or `np.zeros_like(arr)`.
- **If you just need a new list of zeros:** use `[0] * n`.
- **If you must reuse an existing list object:** use `lst[:] = [0] * len(lst)`.

If you tell me whether your array is a **NumPy array**, a **Python list**, or an **array.array**, I’ll give the exact fastest code for that case.
```
